# Provenance

This repository was extracted with file history from the Apache-2.0-licensed
AkiraOS source tree. The extraction maps the reusable CCSDS implementation,
public headers, module integration, tests, sample, and user documentation to
the repository root. Git author names, email addresses, timestamps, and commit
messages are retained in the rewritten path-limited history.

The source boundary was established in AkiraOS commit
`d06141923a59ddf2000c28c8d37dc3138b2cae52`. The extracted history contains
only CCSDS module files and the consumer-independent CFDP UDP integration test.
Akira board configuration, DTS roots, filesystem and installation policy,
application lifecycle, product logging, generated output, and unrelated source
are excluded.

No CCSDS standards, standard PDFs, copied reference documents, captures,
generated test artifacts, or third-party diagrams are distributed here.
Protocol and subset descriptions in the documentation are original summaries
of the implemented behavior.

copied from the source repository. Files that carry SPDX identifiers use
`Apache-2.0`; earlier files without per-file identifiers are distributed under
the same repository-level license.
