# CCSDS module documentation

The documentation is organized by purpose and audience:

- [User guide](user-guide/index.md) — module users integrating the reusable
  library.
- [Development](development/index.md) — developers building, testing, and
  changing this repository.
- [Design](design/index.md) — developers reviewing architecture, state, and
  wire profiles.
- [Reference](reference/index.md) — module users and developers checking
  configuration and supported procedures.
- [Plans](plans/index.md) — maintainers tracking unfinished work.

Sample-specific instructions remain with each sample under `samples/`.
